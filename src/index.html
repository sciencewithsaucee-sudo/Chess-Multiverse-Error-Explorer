Platform Architecture & Purpose

Chess Multiverse Error Explorer is the definitive public research interface designed for deep cognitive and statistical analysis of human chess blunders. It parses the CMEED v1.0 (Chess Multiverse Error & Evaluation Dataset) using serverless DuckDB WASM SQL. This architecture executes lightning-fast, client-side queries, making it an essential, high-performance tool for data scientists, behavioral researchers, and elite grandmaster preparation.

Derived Mathematical Metrics

Expected Score Loss (ESL): Estimated mathematically using a logistic curve mapped over engine evaluation points.

Opening Danger Index (ODI): A composite grade evaluating opening volatility by combining error volume, blunder share, average evaluation drop, unique player count, and time-pressure frequency.

Panic Index: Isolates catastrophic evaluation loss specifically when human players have < 60 seconds remaining on the clock.
